# ENCAFE — A Little Stop Along the Way

**ENCAFE** is a modern, aesthetic café website inspired by the idea of *"en route"* — a little stop along life's journey.

Designed to bring together great coffee, delicious food, refreshing drinks, and delightful experiences, ENCAFE offers a warm and welcoming digital café experience.

---

## About the Project

ENCAFE is a frontend web development project focused on creating a visually appealing and user-friendly website for a contemporary café.

The design follows a **Sunlit & Dreamy** aesthetic, featuring warm neutral colors, elegant typography, beautiful food photography, and a clean layout.

The idea behind the name is simple:

**EN + CAFÉ = ENCAFE**

Inspired by *en route*, ENCAFE represents a place to pause, relax, enjoy something delicious, and continue your journey.

---

## Website Pages

| Page    | Description                                                                                          |
| ------- | ---------------------------------------------------------------------------------------------------- |
| Home    | Introduces ENCAFE and highlights featured products and seasonal specials.                            |
| Menu    | Showcases coffee, cold drinks, bakery items, desserts, ice creams, snacks, and refreshing beverages. |
| About   | Shares the inspiration and story behind ENCAFE.                                                      |
| Contact | Provides contact information and ways to connect with the café.                                      |
| FAQs    | Answers common questions about the café, menu, and services.                                         |
| Careers | Provides information on the job postings in encafé.                                                  |

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd ENCAFE
```

3. Open `Home.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.
